# YAPC — Your Available Proxy Client

Здесь публикуются только готовые сборки (APK, позже Windows/Linux) и подписанный `update-manifest.json`.
Скачать — в разделе [Releases](https://github.com/lan340/YAPC/releases).

**Android:** production — `com.yapc.app`, diagnostic — `com.yapc.app.diag`. Приложение само проверяет и устанавливает обновления.

**Подлинность:**
- манифест обновлений подписан Ed25519 (`update-manifest.json.sig`);
- SHA-256 сертификата подписи APK: `B9:A9:5E:52:43:DF:E6:A2:54:F6:10:E7:9E:DC:F5:B5:BD:85:58:C5:12:3F:A9:A4:CE:05:7C:AB:D9:21:FA:0E`.
